# VitaSUS - Frontend

React + Vite. Telas: login, cadastro de paciente e página inicial com os dados do paciente.

## Como rodar

1. Suba o backend (`npm start` na pasta backend, porta 3000 por padrão).
2. Neste projeto: `npm install` e depois `npm run dev`.
3. Abra http://localhost:5173

Se o backend estiver em outra porta, copie `.env.example` para `.env` e ajuste `VITE_API_URL`.
